# Раскладка

Приложение (PWA) для расчёта питания в походах: GPX-трек, расчёт потребности по Пандольфу, меню, список покупок, рюкзаки.
Открывается как обычный сайт, ставится на телефон и работает офлайн. Данные хранятся только в браузере.

- `index.html` и остальные файлы — полная версия (установка, офлайн).
- `single/index.html` — всё в одном файле (без установки и офлайна).
- Пересборка одного файла: `node build-single.mjs`. Тесты: `node test_gpx.mjs`, `node test_engine.mjs`, `node test_menu.mjs`.
- Решения, принятые без вопросов: `QUESTIONS.md`.
