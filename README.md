# Раскладка v2

Открывается двойным щелчком по `index.html` в Chrome или Edge (Windows). Сервер и установка не нужны, данные хранятся в браузере.

- `index.html`, `styles.css`, `app.bundle.js`, `lib/` — всё, что нужно для работы. Перенести папку на другой компьютер можно целиком.
- `src/` — исходный код. После правки: `node tools/build.mjs` (пересобирает `app.bundle.js`). Только для разработки.
- `pwa-off/` — отключённые `sw.js` и `manifest.json` (установка на телефон и офлайн через сервис-воркер больше не нужны).
- `lib/` — библиотеки (`jszip.min.js`) и шаблон Excel в виде `template.js`. Обновить шаблон: положить новый .xlsx в папку «Шаблон раскладки» и запустить `tools/update-template.ps1` (правый щелчок → «Выполнить с помощью PowerShell»).
- `tests/` — тесты: `node tests/test_engine.mjs`, `test_gpx.mjs`, `test_import.mjs`; отчёт по встроенным блюдам: `node tests/report_dishes.mjs`.
- `Шаблон раскладки/` — шаблон Excel, файл Виктора, его экстракция и пустая форма для загрузки.
- `QUESTIONS.md` — решения, принятые без вопросов.
