## 2. Набор «от Виктора» — точная копия, без подгона

Файл: `C:\Projects\Raskladka\Шаблон раскладки\Калькулятор Виктор.xlsx`.

**Цель:** перенести продукты, блюда и меню Виктора в приложение один в один. Потом мы сверим расчёт и Excel-выгрузку приложения с файлом Виктора. Любое «исправление» данных испортит сверку.

### 2.1 Главное правило: ничего не менять

Запрещено:
- исправлять, округлять, нормализовать или «улучшать» значения;
- подставлять недостающее КБЖУ из встроенных наборов, интернета или своих знаний;
- переводить единицы (шт, ложки, банки, кг) в граммы, пересчитывать «на группу» в «на человека»;
- объединять похожие названия, исправлять опечатки, менять регистр и порядок;
- удалять или заменять продукты и блюда, включая лук и чеснок;
- превращать пустые ячейки в 0 и наоборот;
- применять к данным Виктора правила v2 (минимумы приёмов, запрет лука и чеснока, ротация, масштабирование).

Что сохранять:
- названия — как в файле, символ в символ (пробелы по краям только отметить в отчёте, не удалять);
- числа — с полной точностью, как значение ячейки, а не как оно отображается на экране;
- если ячейка — формула, сохранить вычисленное значение и отметить, что это формула (саму формулу записать в отчёт);
- единицы, порядок строк, группировку по приёмам пищи и дням — как у Виктора;
- для каждой записи — источник: лист и ячейка («Продукты!B14»).

Если что-то не помещается в структуру приложения (лишние поля, свои единицы, примечания), не выбрасывай и не переделывай. Сохрани в дополнительных полях «как в оригинале» и покажи мне в отчёте.

### 2.2 Сначала изучи файл, ничего не создавай

Опиши мне простыми словами:
- листы и что на каждом;
- где продукты и какие у них поля;
- где блюда и их состав (граммы на человека или на группу, на сколько человек);
- есть ли меню-план по дням;
- какие единицы используются;
- какие итоговые расчёты есть у Виктора (ккал, вес, БЖУ по дням, на человека, на группу, закупка).

Составь таблицу соответствия «колонка/ячейка Виктора → поле приложения». Отдельным списком — что нельзя перенести без изменений и почему. Ничего не решай за меня: только перечисли, для каждого пункта предложи варианты и дождись моего ответа.

### 2.3 Создай наборы

- Набор продуктов **«от Виктора»**.
- Набор блюд **«от Виктора»**, привязанный к нему.
- Меню-план **«от Виктора»**, если он есть в файле.
- Все три помечены «оригинал, только чтение»: редактировать нельзя, можно только сделать копию и менять её.
- При применении плана «от Виктора» к походу генератор ничего не добавляет и не масштабирует: ячейки, которые пусты у Виктора, остаются пустыми.
- Если продукт или блюдо не может участвовать в расчёте (нет КБЖУ, единица не в граммах), оно всё равно загружается. В расчёте оно помечается «не считается: <причина>», а не подменяется.
- **Контрольные значения.** Итоги Виктора (ккал, вес, БЖУ по дням, на человека, на группу, закупка) сохрани отдельно как «эталон для сверки». В расчётах они не используются.
- Если вкладок уже 10 — сообщи, ничего не удаляй.

### 2.4 Проверка точности экстракции

- Выгрузи извлечённые данные обратно в Excel в структуре Виктора: те же листы, столбцы, порядок.
- Автоматически сравни с оригиналом ячейка в ячейку: значения, пустые ячейки, количество строк.
- Ожидаемый результат: 0 расхождений. Каждое расхождение — в список с адресом ячейки, «было / стало» и причиной.
- **Отчёт:** сколько продуктов, блюд, дней плана; что не считается и почему; список формул; результат сверки. Без оценок «хорошо/плохо» и без предложений исправить данные Виктора.

## 3. Загрузка продуктов, блюд и меню из файлов

### 3.1 Кнопки

| Кнопка | Где | Что делает |
|---|---|---|
| «Загрузить продукты» | вкладки наборов продуктов | файл → один набор продуктов |
| «Загрузить блюда» | вкладки наборов меню | файл → один набор блюд |
| «Загрузить меню (план)» | экран «Расчёт» и вкладки наборов меню | файл → план по дням |
| «Загрузить всё из одного файла» | Настройки и обе панели вкладок | система сама находит продукты, блюда и план и раскладывает по вкладкам |

Форматы: `.xlsx`, `.xls`, `.csv`, `.json`. Один файл может содержать один лист или много листов.

### 3.2 Автораспознавание (для «Загрузить всё»)

Распознавай содержимое:
- по названиям листов;
- по заголовкам колонок;
- по форме данных.

Блоки могут быть на разных листах или друг под другом на одном листе (блоки разделены пустыми строками или заголовками).

**Словарь синонимов заголовков** храни в одном месте, чтобы легко дополнять. Примеры:

| Поле | Синонимы |
|---|---|
| Название | Продукт, Наименование |
| Ккал | Калорийность, Энергия, ккал/100г |
| Белки | Б, Белок |
| Жиры | Ж |
| Углеводы | У |
| Граммы на человека | Г_на_чел, Норма, Вес на чел, г/чел |
| Граммы на группу | Всего, На группу |
| Приём пищи | Завтрак/Обед/Ужин/Перекус как значения или заголовки блоков |
| День | День, Дата, Д1/Д2 |

Признаки:
- **Продукты:** есть КБЖУ на 100 г.
- **Блюда:** есть название блюда + продукт + граммы.
- **План:** есть дни × приёмы → названия блюд.

Мой шаблон «Калькулятор раскладки шаблон» и выгрузка самого приложения тоже должны загружаться обратно (проверка «туда-обратно»).

### 3.3 Окно предпросмотра (обязательно перед загрузкой)

- Что найдено: «Продукты: 84 → новая вкладка “<имя файла>”», «Блюда: 23 → …», «План: 10 дней → …».
- Для каждого блока можно выбрать:
  - куда загрузить: новая вкладка (имя редактируется) или существующая;
  - режим: добавить к существующим / заменить вкладку целиком;
  - не загружать этот блок.
- Совпадения названий: обновить / пропустить / сохранить оба (с суффиксом). Можно выбрать «для всех».
- Ошибки построчно: «лист Блюда, строка 14: нет граммов». Плохие строки пропускаются, остальное грузится.
- Нераспознанные колонки и листы — списком «не использовано». Если блок не распознан — дать мне вручную указать тип и соответствие колонок.
- **Честная загрузка по умолчанию:** данные грузятся как в файле, без автоматических исправлений и подстановок.
- **Единицы:** кг, шт, ложки, банки и граммы на группу не пересчитываются молча.
  - По умолчанию выбрано «оставить как в файле»: такая строка не участвует в расчёте и помечается.
  - Пересчёт — только если я сам выберу его в окне: кг → г; вес одной штуки (запоминать для следующих загрузок); на сколько человек «на группу».
- **Связи:**
  - продукты в блюдах, которых нет в наборе продуктов: оставить с предупреждением (по умолчанию) / создать из этого же файла / связать с существующим продуктом;
  - блюда в плане, которых нет в наборе блюд: то же самое.

### 3.4 Отдельные файлы

Каждая кнопка («Загрузить продукты / блюда / меню») грузит в свою вкладку через то же окно предпросмотра. Тип блока уже задан кнопкой. Если в файле есть ещё и другие блоки — предложить загрузить и их.

### 3.5 Ограничения

- Не больше 10 вкладок каждого типа. Если места нет — предложить загрузить в существующую вкладку.
- Загрузка не трогает текущий поход, пока я не нажму «Применить план».
- Кнопка «Отменить последнюю загрузку».
