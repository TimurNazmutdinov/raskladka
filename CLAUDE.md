# Раскладка

Офлайн-веб-приложение для планирования продуктов и меню походов. Чистый JavaScript (ES-модули), без фреймворков и без сервера. Открывается двойным щелчком по `index.html` в Chrome/Edge; данные хранятся в браузере. Экспорт в Excel через `lib/jszip.min.js` и встроенный шаблон `lib/template.js`.

Структура: `src/` — исходники, `app.bundle.js` — сборка (её и грузит `index.html`), `lib/` — библиотеки и шаблон, `tests/`, `tools/`, `pwa-off/` — отключённая PWA, `sw.js` — воркер, удаляющий сам себя (для тех, кто ставил v1), `Шаблон раскладки/` — Excel-шаблон и данные. Подробности — в `README.md`, `TZ_raskladka.md`, `QUESTIONS.md`.

## Команды
- Сборка после правки `src/`: `node tools/build.mjs`
- Тесты: `node tests/test_engine.mjs`, `node tests/test_gpx.mjs`, `node tests/test_import.mjs`
- Отчёт по встроенным блюдам: `node tests/report_dishes.mjs`
- Обновить встроенный шаблон Excel (из папки «Шаблон раскладки»): `powershell -ExecutionPolicy Bypass -File tools\update-template.ps1`
- Python-скрипты в `tools/` (`extract_victor.py`, `make_form.py`, `verify_form.py`) нужны только при наличии файлов Виктора; зависимостей не требуют.

## Постоянные правила работы
- Перед изменением экранов сначала показывай эскиз и жди согласия.
- Делай только то, что просили, ничего сверх задачи.
- Объясняй коротко и простым языком.
- Экономь токены: читай только нужные файлы, не весь код.
- Решения, принятые без пользователя, записывай в `QUESTIONS.md`.
- Данные Виктора не изменять и не коммитить (они в `.gitignore`).
